## Approval record format

`ExperimentConfig.approvals` requires `decisionId`, author-selected `selection`, `approvedAt`, and a durable `approvalRef`. The code rejects missing approvals. A populated parameter alone is not an approval. Approval does not automatically implement a selected semantic: S9 remains blocked until the selected Γ interpretation is wired to the generator and evaluator.
