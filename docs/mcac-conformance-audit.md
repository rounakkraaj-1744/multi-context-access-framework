# MCAC Formal Conformance Audit

## Scope and evidence

I independently extracted all 17 pages of `complete_research_paper.pdf` and inspected the implementation under `lib/mcac` and its tests. Page references below are PDF page numbers (the printed page is the same except the cover). “Tested” means an executable test exercises the behavior; it is not a proof of a proposition. Existing `replayTrace` is not independent evidence because it calls `evaluateMcac`.

## Classification summary

1. **Formally verified against manuscript:** none by executable tests alone; the equations have been independently transcribed and reviewed, but implementation proofs are not machine-checked.
2. **Implemented and covered by tests, not independently verified:** validity precedence, severity/aggregation/decision mapping, baseline gate, policy snapshot behavior, trace hashing basics.
3. **Partially implemented:** provider/source lint, Γ predicate evaluation, complete trace replay, independent evaluator coverage and Eq. (19) corpus metric.
4. **Blocked by author clarification:** Γ category scope, valid-but-unlisted network threshold behavior, exact waiver expiry endpoint, exhaustive `⊕` grammar.
5. **Not implemented:** production context providers/integration, coverage metric (18), external hash-head anchoring, experiment harness/results and corpus RF report.

Detailed alternatives for the four open definitions are in [mcac-author-decisions.md](mcac-author-decisions.md). No production authorization route or existing application record was changed in this audit.
